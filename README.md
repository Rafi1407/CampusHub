# CampusHub

A Java Swing-based Smart Student Collaboration Platform.

## How to Run the Project
1. Clone or download this repository.
2. Open the project in any Java IDE (IntelliJ IDEA, Eclipse, or NetBeans).
3. Ensure the `data` directory stays at the project root level.
4. Navigate to `src` and run **`Main.java`** 

## Requirements
* Java Development Kit (JDK) 11 or higher.
